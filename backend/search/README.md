# SEQUENCE SEARCH

**Status:** prototype for Nov 13 demo

## What it does
Lets users search a DNA or protein sequence against the customer’s genomes and find where it matches. For the demo this runs on SequenceServer; later it will run NCBI BLAST+ directly behind our own API.
