# REACT FRONTEND

**Status:** prototype for Nov 13 demo

## What it does
The single web interface for Genome AB, built in React. At this stage it includes the custom pathotyping page, an embedded JBrowse genome browser showing the customer’s genomes and variants, and SequenceServer for sequence search.
