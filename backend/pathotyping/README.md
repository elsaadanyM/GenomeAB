# PATHOTYPE CLASSIFICATION

**Status:** prototype for Nov 13 demo

## What it does
Classifies *P. brassicae* isolates into pathotypes. It takes user input (and/or an uploaded Excel file) of disease ratings, runs the pathotyping pipeline (ported from R to Python), and returns the pathotype, reaction pattern, Disease Severity Index (DSI) and QC results under the CCD and Williams systems.
